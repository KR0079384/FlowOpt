# Frontend API Client Context (`frontend/src/api/api.md`)

## A. Directory Purpose
`frontend/src/api` encapsulates all HTTP network communication between the React client and the FlowOpt backend API running on port 8000.

## B. File Index
- `frontend/src/api/api.md`: This context documentation file.
- `frontend/src/api/client.ts`: Typed fetch wrappers for factory state, reset, disruption injection, recovery optimization, and scenario preset loading.
